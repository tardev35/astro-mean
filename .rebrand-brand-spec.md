## Non-negotiables for every agent

1. **Unused component variants are inventory — never delete one.**
2. **Do NOT run `npm run build`.** The orchestrator runs the single build in Phase 5.
3. Only article content may produce `<h1>/<h2>/<h3>`. Chrome labels are `<p>`/`<span>`
   + `aria-label` on the section. This docx is flat H1+H2 → **the rendered pages must
   contain zero `<h3>`**.
4. No HTML comments (`<!-- -->`) in anything that renders — Astro ships them.
   Strip existing ones from every component you retheme.
5. Body copy: `text-left text-base leading-relaxed`. No `mx-auto max-w-*` on `<p>`.
6. Never type a domain or build a URL with `+`. Use `pageGraph()` / `abs()`.
7. No `Review`, `AggregateRating`, `sameAs`, `address`/`PostalAddress`, `email` in JSON-LD.
8. `*FloatingBadge` variants: check the title badge has no `whitespace-nowrap`
   (use `w-[92%] max-w-2xl text-center`) and that `pt-*` clears a 2-line title.
9. Never hand-write `isActive` — import `isActivePath` from `../lib/nav`.
10. No `define:vars`, no `href="#"`, no `onclick=`, `alt` must describe the picture,
    decorative emoji need `aria-hidden="true"` on their own span.
