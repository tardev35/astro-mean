## 2. พาเลตต์ — ทองบูสต์ + น้ำเงินไฟฉาย บนพื้นดำน้ำเงิน

โลโก้ BOOST168 = ตัวอักษร `BOOST` โครเมียมขอบน้ำเงิน + เลข `168` ทองส้ม
มีจรวดพ่นไฟส้ม-แดง บนพื้นอวกาศดำน้ำเงิน มีเส้นแสงน้ำเงิน/แดงพุ่ง
(`palette.json` → logo vivid = `#fec533`, `#fee56b`, `#fe9c6a`)

**สีหลัก = ทอง/แอมเบอร์ · สีรอง = น้ำเงินไฟฟ้า · พื้น = ดำน้ำเงิน**

| ทองอ่อน (ไฮไลต์) | `#ffe680` |
| **ทอง (สีหลัก)** | `#ffc233` |
| ทองเข้ม / ส้มไฟจรวด | `#b26a00` |
| น้ำเงินอ่อน | `#9ecbff` |
| **น้ำเงินไฟฟ้า (สีรอง)** | `#3f8cff` |
| น้ำเงินเข้ม | `#12306e` |
| พื้นเพจ (base) | `#050818` |
| พื้นการ์ด / panel | `#0e1430` |
| พื้น panel เข้มขึ้น | `#03060f` |
| พื้น panel สว่างขึ้น | `#18204a` |

| ขาวอมทอง (หัวข้อ gradient หัว) | `#fff6dd` |

```

#ffd85e            -> #9ecbff        (ทองอ่อนเก่า   -> น้ำเงินอ่อน)
#0f0320            -> #050818        (พื้นเพจ)
```

ถ้าเจอ hex ของแบรนด์เก่ากว่านั้น (MONACO89 ส้ม `#ef8f22`/`#ffd77a`/`#a44516`/`#160d05`,
MAHAHENG333 ทองแดง `#e8b923`/`#f3e2b8`/`#c2a469`/`#0a0704`/`#b4231c`/`#221708`)
ให้แมปเข้าพาเลตต์ข้างบนด้วยหลักเดียวกัน: ทอง→`#ffc233`, ทองอ่อน→`#ffe680`,
พื้นเข้ม→`#03060f`/`#050818`, แดง/ส้มเข้ม→`#b26a00`, ตัวอักษรจาง→`#9ecbff` หรือ `#e6ecfb`

**ห้ามแตะ**: เขียว LINE `#00B900`, สีโลโก้ธนาคารใน `BankStrip`, สีเขียว live/success

## 5. Checklist หัวข้อ docx — ต้องครบ 7 ข้อ เรียงตามนี้เป๊ะ

หน้าแรกต้องได้ **h1 ×1 + h2 ×6 (+ h2 ของ FAQ = 7) และ h3 ×0**

1. **H1** — `BOOST168 สล็อตเว็บตรงจัดหนัก เกมดีมีบูสต์ ระบบไวไม่เกินจริง`
   > เตรียมพบกับมิติใหม่ของการปั่นสล็อตที่เข้าถึงง่ายและเร้าใจยิ่งกว่าเดิมที่ BOOST168 เว็บตรงสายลุยที่ไม่ได้มีดีแค่คำคุย แต่จัดหนักให้จริงทั้งเรื่องค่ายเกมและอัตราการจ่ายรางวัล ที่นี่ถูกออกแบบมาเพื่อเติมเต็มความตื่นเต้นให้ผู้เล่นทุกระดับ ด้วยระบบการทำงานที่เสถียร สมูธ และตอบสนองได้อย่างรวดเร็วแบบไม่เกินจริง ลืมภาพเว็บสล็อตที่โฆษณาเกินจริงไปได้เลย เพราะที่นี่เน้นให้คุณได้สัมผัสความสนุกของการสปินแบบลื่นไหล ลุ้นโบนัสได้แบบต่อเนื่องในทุกๆ วัน

2. **H2** — `BOOST168 สล็อตเว็บตรงจัดหนัก เปิดคลังเกมใหม่ให้มีตัวเด็ดตามต่อไม่ขาดช่วง`
   > ไม่มีคำว่าเหงาหรือจำเจเมื่อเข้ามาใช้งานที่ BOOST168 เพราะที่นี่มีการอัปเดตคลังเกมสล็อตใหม่อยู่ตลอดเวลา ขนเอาเกมตัวตึงจากทุกค่ายชั้นนำมารวบรวมไว้ให้เลือกเล่นอย่างจุใจ ไม่ว่าจะเป็นเกมแนวสตรีทสุดมันส์ แนวแฟนตาซีเวทมนตร์ หรือแนวคลาสสิกโบนัสแตกง่าย ทุกเกมถูกคัดสรรมาแล้วว่ามีคุณภาพสูง กราฟิกสวยงาม และมีจังหวะการจ่ายรางวัลที่น่าลุ้น ให้คุณได้เปลี่ยนบรรยากาศเล่นเกมเด็ดตามกระแสได้แบบไม่ขาดช่วง

3. **H2** — `เกมดีมีบูสต์ตรงไหน? ลองแกะฟีเจอร์เด็ดที่ทำให้แต่ละเกมมีลูกเล่นมากขึ้น`
   > นิยามคำว่าเกมดีมีบูสต์ของ BOOST168 ไม่ใช่แค่เรื่องภาพสวย แต่หมายถึงตัวเกมที่อุดมไปด้วยฟีเจอร์ช่วยเพิ่มโอกาสการทำกำไรแบบจัดเต็ม ไม่ว่าจะเป็นฟีเจอร์สุ่มคูณเงินรางวัล ฟีเจอร์รีสปินล็อกสัญลักษณ์ หรือโหมดฟรีสปินที่ออกบ่อยและเข้าถึงได้ง่าย ลูกเล่นเสริมเหล่านี้แหละที่เข้ามาช่วยยกระดับความสนุก ทำให้การหมุนวงล้อในแต่ละรอบมีความหมายมากกว่าแค่การลุ้นสัญลักษณ์ธรรมดา เพิ่มมิติความตื่นเต้นให้ปั่นเพลินได้ตลอดวัน

## 7. กฎที่ทุก Agent ต้องถือ

1. **ห้ามลบ component variant ที่ไม่ได้ใช้** — เป็น inventory ของแบรนด์ถัดไป
2. **ห้ามรัน `npm run build`** — orchestrator รันครั้งเดียวตอนจบ
3. **ห้ามแตะไฟล์ของ agent อื่น** และห้ามแตะ shared chrome (ดูรายชื่อในบรีฟของแต่ละ agent)
4. **ห้ามเหลือ HTML comment `<!-- ... -->`** ในไฟล์ที่ render จริง (Astro ส่งออกไปที่ dist)
   — คอมเมนต์อธิบายให้ย้ายไป frontmatter (`// ...`)
5. **มีแต่เนื้อหาบทความเท่านั้นที่เป็น heading ได้** — ป้าย widget/ป้ายคอลัมน์/ป้าย card
   ต้องเป็น `<p>`/`<span>` + `aria-label` บน `<section>` ห้ามเป็น `<h1..h6>`
6. **emoji ตกแต่งต้องอยู่ใน element ที่มี `aria-hidden="true"` ของตัวเอง** ห้ามต่อในข้อความ
7. **ห้าม `href="#"` / `onclick=`** · ปุ่มกลับขึ้นบนใช้ `href="#top"`
8. **`alt` ต้องบรรยายภาพ** ห้ามเป็น `"bank"` / `"ภาพที่ 3"`
9. **ห้ามเขียน JSON-LD เอง** — ใช้ `pageGraph()` จาก `src/lib/schema.ts` เท่านั้น
   ห้ามใส่ `Review` / `AggregateRating` / `sameAs` / `address`
10. **ห้ามเขียนโดเมนตรงๆ** ที่ไหนก็ตาม — URL มาจาก `abs()`/`pageGraph()` เสมอ
11. **ห้ามใช้ `define:vars`** และห้ามย้าย logic จาก `src/lib/` กลับเข้า component
12. **ห้ามใส่ `<style>` ที่มีแต่ `.font-sans { font-family: var(--font-sans) }`**
13. เนื้อความในกล่อง: `text-left text-base leading-relaxed` เสมอ ห้าม `mx-auto max-w-*` ในหน้า
14. slot หนึ่งช่อง = หนึ่ง element เท่านั้น (ถ้าต้องหลายบล็อก ให้ห่อ `<div>` เอง)
