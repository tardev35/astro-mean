## 7. Rules every agent must hold (from SKILL.md — not optional)

- **Unused component variants are inventory, never dead code. Delete nothing.**
- **Do NOT run `npm run build`.** The single build belongs to the orchestrator.
- Only article content may produce a heading. Chrome (navbar, footer, ticker,
  winners feed, widget labels, FAQ heading, column labels) renders its label as
  `<p>`/`<span>` + `aria-label` on the section — never `<h1>/<h2>/<h3>`.
- **No HTML comments** (`<!-- … -->`) in anything that renders — Astro ships
  them to `dist/`. Strip them from every component you retheme. Put notes in
  the frontmatter (`//`) instead.
- Body copy in a content box: `text-left text-base leading-relaxed`. No
  `mx-auto max-w-*` on `<p>` in a page. No `text-sm`/`text-lg` for prose.
- Do not re-add a slot wrapper `<div>` to any `ContentBox*` — they are all
  flattened (`isolate` on the card + `-z-10` on decorative layers).
- Never write `isActive` by hand in a navbar — `isActivePath` from `../lib/nav`.
- Never use `define:vars` on an indexable page. Never reintroduce Swiper.
- JSON-LD comes from `pageGraph()` only. Never type a domain, never build a URL
  with `+`, never add `Review`/`AggregateRating`/`sameAs`/`address`.
- `alt` must describe the picture — open the image and read what is printed on
  it. Decorative repeats get `alt=""` + `aria-hidden` on the wrapper.
- Decorative emoji live in their own `<span aria-hidden="true">`, never inside
  label text and never inside a text prop (so: no leading emoji in the
  announcement `message`).
- No `href="#"`, no `onclick=`. Back-to-top is `href="#top"`.
- Every `description` you write: **150–160 characters** (count characters, not
  bytes — Thai is 3 bytes/char). Check with
  `python -c "print(len('…'))"`.
- `<Image>`/`<Picture>` always get `widths` + `sizes` describing how wide the
  image is **drawn**.
- Do not add a `<style>` block that only contains `.font-sans { … }`.
- Do not touch `src/styles/_sources.generated.css` (build-generated), and do
  not touch `src/lib/*` or `astro.config.mjs` / `wrangler.toml` — the
  orchestrator owns those.
